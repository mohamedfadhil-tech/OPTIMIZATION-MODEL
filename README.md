# 🧠 Task 4 - Business Optimization using Python (No External Libraries)

## 📌 Task Description

This project solves a simple **business optimization problem** using Python, as part of Task 4 of the CODTECH Data Science Internship.

We aim to **maximize profit** by deciding how many chairs and tables to produce, based on **resource constraints** like wood and labor. This solution is compatible with **Programiz** and similar online compilers that do **not support external libraries**.

---

## 🚀 Problem Statement

A furniture company produces:
- **Chairs** (profit: ₹20 each)
- **Tables** (profit: ₹50 each)

Each product consumes:
- Wood: 5 units per chair, 20 per table (total available: 400 units)
- Labor: 10 hours per chair, 15 per table (total available: 600 hours)

### Objective:
Maximize total profit while staying within resource constraints.)
